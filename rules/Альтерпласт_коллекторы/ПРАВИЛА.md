# Правила моделирования семейств — «Альтерпласт»: коллекторы (многопортовые детали)

Версия 1.0 · Nov 13, 2026 · Revit 2019 · профиль `alterplast-multiport` (`rules/Альтерпласт_коллекторы/profile.json`)

## Когда применять

Только для проекта «Альтерпласт» и только для многопортовых соединительных деталей: коллекторы PP-R (магистраль + отводы); по тем же правилам — тройники и крестовины. Профиль включается, когда пользователь называет проект и деталь многопортовая.

**Основа — правила профиля `alterplast` версии 1.1** ([ПРАВИЛА.md](../Альтерпласт/ПРАВИЛА.md)). Профиль наследует его (`"extends": "alterplast"`): `get_family_rules profile: "alterplast-multiport"` возвращает правила обоих профилей одним вызовом, а в `profile.json` записаны только отличия. Все правила ALT-01…ALT-23 действуют, кроме заменённых ниже: они написаны для проходной детали с двумя концами на одной оси.

| Правило основы | Что с ним | Почему |
|---|---|---|
| ALT-05 «все коннекторы связаны» | → **MP-01** | Revit связывает коннекторы только попарно: связана магистраль, отводы — без пары |
| ALT-06 «Y всех коннекторов вверх» | → **MP-02** | У отвода, который смотрит вниз, ось Y не может смотреть вверх |
| ALT-14 «центр габаритов по X, Y, Z» | → **MP-03** | Ушки сверху, отводы снизу, ручки спереди: деталь несимметрична, а вставляется по оси магистрали |
| ALT-10 «не больше 6 форм» | → **MP-04** | Ориентир зависит от числа отводов |
| ALT-18 категория и тип детали | дополнено **MP-05** | В таблице ALT-18 коллекторов нет |
| ALT-11 «тело вращения вдоль X» | дополнено **MP-06**, **MP-07** | У коллектора ещё n тел вращения вокруг вертикальных осей и станции отводов |

Остальное — как в основе: таблица выбора с ключом `DN1` (ALT-01), материал (ALT-02), «Фитинг» (ALT-07), LOD 300 (ALT-08), плоскости во всех видах (ALT-15), коннектор в глубине раструба (ALT-19), имена из ИД (ALT-20), округление (ALT-21), источники ADSK (ALT-22), пакетная выгрузка таблиц (ALT-23).

## Правила

| № | Правило | Проверка |
|---|---|---|
| MP-01 | Магистраль: 2 коннектора на оси X, связаны, главный — на магистрали | Авто (`mainRun`) |
| MP-02 | Ориентация коннектора по направлению: горизонтальный — Y вверх, вертикальный — Y вдоль магистрали | Авто (`connectorOrientationByDirection`) |
| MP-03 | Начало координат — центр магистрали: центр габаритов по X, коннекторы магистрали на оси X | Авто (`origin` по X + `mainRun`) |
| MP-04 | Повторяющиеся элементы — одной формой; ориентир — не больше 10 форм | Авто (`singleGeometry`) |
| MP-05 | Категория `OST_PipeFitting`, тип детали `MultiPort` | Авто (`category`, `partType`) |
| MP-06 | Отводы — тела вращения вокруг вертикальной оси на станции; эскиз и ось закреплены | Авто (гибкость) + `lock_family_sketch` |
| MP-07 | Станции отводов и ушек: шаг из ИД и равные доли (EQ) | Вручную + гибкость |
| MP-08 | Одно семейство на число выходов | Вручную |

### MP-01. Магистраль и отводы (вместо ALT-05)

Два коннектора магистрали смотрят в ±X, стоят на оси X через начало координат и связаны друг с другом; левый — главный. Коннекторы отводов не связаны: Revit связывает коннекторы только попарно, а поток в отвод — ответвление.

Сделать: `setup_family_connectors link: [[лев, прав]], primary: лев, up: [0, 0, 1]`.

Проверка: `mainRun` — ровно 2 коннектора вдоль `axis`, в разные стороны, не дальше `toleranceMm` от оси, связаны друг с другом, главный среди них; остальные считаются отводами.

### MP-02. Ориентация коннектора по его направлению (вместо ALT-06)

- Горизонтальный коннектор (магистраль): ось Y — вверх (+Z), как в ALT-06.
- Вертикальный коннектор (отвод вниз или вверх): ось Y — вдоль магистрали (+X). Тогда коллектор, вставленный отводом в стояк, не поворачивается вокруг стояка.

Сделать — тем же `setup_family_connectors`, вторым вызовом: `up: [1, 0, 0], autoLink: false`. Коннекторы магистрали смотрят вдоль X, команда их пропускает, а Y отводов поворачивает на +X. Первый вызов (`up: [0, 0, 1]`) делает наоборот: ориентирует магистраль, отводы пропускает. Новой команды не нужно.

Проверка: `connectorOrientationByDirection` (`up`, `verticalY`).

### MP-03. Начало координат — центр магистрали (вместо ALT-14)

- По X центр габаритов в начале координат: плоскость «По центру (Влево/Вправо)» делит магистраль пополам (EQ торцов).
- По Y и Z габарит несимметричен (ушки, отводы, ручки) — по ним проверяется не центр габаритов, а то, что ось магистрали проходит через начало координат: коннекторы магистрали на оси X (MP-01). «Опорная плоскость» — ось магистрали, «По центру (Вперёд/Назад)» — плоскость симметрии корпуса.

Проверка: `origin` с `axes: ["X"]` и `mainRun`.

### MP-04. Повторяющиеся элементы — одной формой (уточняет ALT-10)

Одинаковые элементы всех отводов в одной плоскости — одно выдавливание с несколькими контурами: ручки вентилей, ушки, стержни коннекторов отводов. Каждый контур закрепляется на своих плоскостях (`lock_family_sketch`). Тело вращения у каждого отвода своё (одна ось вращения на форму).

Формы коллектора на n отводов: магистраль 1 + отводы n + ручки 1 + ушки 1 + стержень магистрали 1 + стержни отводов 1 = n + 5. Ориентир `maxForms` — 10 (до 5 отводов).

Массив (`create_family_array`) для отводов не годится: на элемент массива не ставится коннектор.

### MP-05. Категория и тип детали (дополняет ALT-18)

| Деталь | Категория | Тип детали |
|---|---|---|
| Коллектор (магистраль + n отводов) | `OST_PipeFitting` | `MultiPort` |

`MultiPort` в Revit 2019 есть (проверено: `Enum.GetNames(typeof(PartType))`). Встроенные вентили — часть коллектора, не отдельная арматура.

Проверка: `category` + `partType` (`allowed: ["MultiPort"]`).

### MP-06. Отводы — тела вращения на станциях (дополняет ALT-11)

Отвод (корпус вентиля + раструб) — тело вращения вокруг вертикальной оси на плоскости станции `Отвод_j`; профиль — в плоскости XZ (`create_family_revolution`, ось `{start: [x_j, 0], end: [x_j, z_низ]}`).

Закрепить на плоскостях:
- линию профиля на оси — на `Отвод_j`, внешние вертикальные линии — на `Отвод_j_В_П` (корпус вентиля) и `Отвод_j_Р_П` (раструб);
- горизонтальные линии — на «Опорная плоскость», `Ступень`, `Низ`;
- **ось вращения — на `Отвод_j`.** Без этого при сдвиге станции профиль уезжает, а ось остаётся на месте, и тело ломается. Ось — отдельная линия эскиза (`Revolution.Axis`); `NewAlignment` с ней в Revit 2019 работает (проверено: ось и профиль сдвигаются вместе, объём совпадает).

Сделать: `lock_family_sketch forms: [{elementId, planes: [...], axis: true}]`. Это та же логика, что генератор муфт закреплял кодом через `send_code_to_revit`, плюс ось вращения. Закрепляются все прямые линии, которые лежат в перечисленных плоскостях; незакреплённые возвращаются в `free`.

Диаметры, которые одинаковы во всех строках (корпус вентиля, раструб отвода), всё равно задаются парой плоскостей с меткой и EQ вокруг станции: плоскости должны ехать вместе со станцией.

### MP-07. Станции отводов и ушек (дополняет ALT-11, ALT-17, ALT-20)

- Отводы — плоскости `Отвод_1…n`, ушки — `Ушко_1…n−1` посередине между отводами. У чётного n среднее ушко — плоскость «По центру (Влево/Вправо)» (своя плоскость дала бы второе условие на ту же точку).
- n ≥ 3: размер `L1` (имя из ИД) — между крайними ушками; EQ всех ушек и EQ крайних ушек относительно центра; каждый отвод — EQ между соседними ушками, крайние отводы — EQ «отвод, ушко, соседний отвод». Шаг отводов = `L1/(n−2)`; отдельного параметра шага нет.
- n = 2: в ИД `L1 = 0`, размерной цепочки из ушек нет: параметр `Шаг` (ALT-17, из строк с 3–5 выходами) между отводами + EQ относительно центра; ушко одно, на центре.
- Ширина ушка `B_ушко` — пара плоскостей с меткой и EQ вокруг центра ушка.

Значения шага из ИД берутся как есть, даже если похожи на опечатку (`L1 = 47` у 40x20x3 при 46 у остальных): спорное — в «Расхождения ИД», решение — за проектом.

### MP-08. Одно семейство на число выходов

Число коннекторов в семействе постоянное, поэтому коллекторы на 2, 3, 4 и 5 выходов — разные семейства. Внутри семейства ключ таблицы — `DN1` (Ду магистрали), `d1` — Ду отводов, столбец таблицы.

## Как сделать в Revit 2019

| Шаг | Команда | Заметки |
|---|---|---|
| Плоскости | `create_family_reference_planes` | X — на виде «Спереди», `extent`/`depth` по габаритам строк (ALT-15) |
| Размеры | `create_family_dimensions` | `L1`/`Шаг`, EQ станций (MP-07), пары плоскостей диаметров |
| Магистраль | `create_family_revolution` | профиль в XZ, ось по X — как тело муфты |
| Отводы | `create_family_revolution` × n | ось вертикальная на станции (MP-06) |
| Ручки, ушки, стержни отводов | `create_family_extrusion` | плоскость XZ (нормаль −Y), по контуру на отвод (MP-04) |
| Закрепление | `lock_family_sketch` | все формы одним вызовом, `axis: true` для отводов |
| Стержень магистрали | `create_family_extrusion` + `align_family_elements` | как у муфт (ALT-19) |
| Коннекторы отводов | `create_family_connector` | на нижних гранях стержней отводов; грань своего отвода — по `originMm` X из `get_family_geometry` |
| Связь и ориентация | `setup_family_connectors` × 2 | MP-01, MP-02 |
| Проверки | `test_family_flex`, `check_family_rules profile: "alterplast-multiport"` | |

Стержни коннекторов отводов — прямоугольник шириной Ø раструба отвода (по `Отвод_j_Р_Л/П`), чтобы центр нижней грани был на оси отвода: коннектор ставится в центр грани. Стержни скрыты параметром формы «Видимый» = нет (ALT-19).

## Порядок работы

1. `get_family_rules profile: "alterplast-multiport"` — придут и правила основы (`alterplast`), и этот профиль.
2. ИД (ALT-09, ALT-17): таблица → L, L1, D, d, d1; недостающее — доли чертежа; глубина раструба — по ИД муфт TEBO (783-790), если в ИД коллектора её нет.
3. `new_family` → `set_family_properties category: OST_PipeFitting, partType: MultiPort, alwaysVertical: true, shared: false`.
4. Параметры ADSK (ALT-13), `DN1`, размеры (ALT-20, ALT-21), `LT` → таблица выбора.
5. Плоскости и размеры (MP-07).
6. Формы (MP-04, MP-06) → `lock_family_sketch` → стержни → коннекторы → `setup_family_connectors` × 2.
7. Материал, таблица выбора, формулы, описания параметров.
8. `test_family_flex` по всем строкам → `check_family_rules profile: "alterplast-multiport"` → сохранить → `export_family_lookup_tables` (ALT-23).

Генератор по этим правилам — `Альтерпласт/Коллекторы/генератор` в папке исходных данных (`REVIT_MCP_DATA_DIR`), README там.

## Кандидаты в общие (Global) правила и команды

По концепции общих и проектных наборов (команды и правила проекта переходят в общие после проверки человеком):

- `lock_family_sketch` — не зависит от проекта: закрепление эскиза и оси вращения нужно любому параметрическому семейству.
- Проверки `mainRun`, `connectorOrientationByDirection`, `partType` — универсальные функции `check_family_rules`, проектного в них только пороги в профиле.
- MP-01, MP-02, MP-06 — по сути общие правила MEP-фитингов, а не «альтерпластовские».
