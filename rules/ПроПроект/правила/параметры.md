# Правила проекта «ПроПроект» — параметры, имя, категория

Профиль `proproekt`, версия 0.1 (черновик: ждёт проверки человеком). Пакет `adsk` подключён ради ФОП и GUID; из его состава проект требует только три параметра (PP-04), проверку материала `ADSK_Материал` проект отключает.

| № | Правило | Проверка |
|---|---|---|
| PP-04 | Заполнены только `ADSK_Наименование`, `ADSK_Позиция`, `ADSK_Марка` | Авто (`requiredParameters`) + вручную значения |
| PP-05 | Имя семейства: `Позиция_Марка_Наименование_Габариты` | Вручную |
| PP-06 | Повторяющееся оборудование — одно семейство-образец, меняются имя, марка, позиция | Вручную |
| PP-10 | Категория: как у исходника; в 2019 нет «Медицинского оборудования» | Авто (`category`) + вручную |

### PP-04. Три параметра ADSK

Общие параметры из `ФОП2019.txt` (тот же, что у Альтерпласта), GUID — из ФОП:

| Параметр | Тип / экземпляр | Значение | Пример |
|---|---|---|---|
| `ADSK_Наименование` | тип | основная информация, без характеристик (колонка G) | Стол медицинский |
| `ADSK_Позиция` | экземпляр | позиция спецификации как есть (колонка I) | 3.01, б/п |
| `ADSK_Марка` | тип | «Тип, марка, обозначение» без «или аналог»; нет — прочерк (колонка J) | 1200 СЛНл-У, - |

Остальные параметры ADSK не добавляются и не заполняются. Параметры исходного семейства (размеры, материалы, «Модель», «Изготовитель») в 2019 не переносятся.

Сделать: `add_family_shared_parameters` с ФОП из `get_family_rules profile: "proproekt"`, затем `set_family_parameter_values`.

Проверка: `requiredParameters` — три параметра есть, общие, GUID совпадает с ФОП, `ADSK_Позиция` — экземпляра. Значения сверить с таблицей вручную.

### PP-05. Имя семейства

`Позиция_Тип, марка_Наименование_Габариты` — готовое имя в колонке K таблицы:

- `3.01_1200 СЛНл-У_Стол медицинский_1200х600х750`
- `бп_MB5000MP_Газификатор криогенный_2100х2100х3180`
- `бп_Рулонная штора медицинская_1500х2000` — марки нет, часть пропущена
- `5.08_Biosafe 120_Криохранилище_Ø560х1140` — цилиндр

В позиции «/» убирается (`б/п` → `бп`), в марке «/» и другие запрещённые в имени файла знаки заменяются на «-». Габариты — Ш×Г×В по спецификации, разделитель — русская «х». Нет габаритов в спецификации — часть пропускается. Типоразмер в семействе один, его имя совпадает с именем семейства.

### PP-06. Повторяющееся оборудование

Если одно и то же изделие стоит на нескольких позициях (АРМ 7.03, 7.06, 7.12), делается одно семейство-образец, а остальные — его копии, в которых меняются только имя семейства, `ADSK_Наименование`, `ADSK_Марка` и `ADSK_Позиция`. Геометрию в копиях не трогать.

### PP-10. Категория

| Что | Категория 2019 | Шаблон 2019 |
|---|---|---|
| Исходник «Медицинское оборудование» (нет в 2019) | Специальное оборудование | `Метрическая система, специальное оборудование.rft` |
| Исходник другой категории | как у исходника | по категории |
| Кубик: столы, стулья, кресла, шкафы, тумбы, стеллажи, скамьи, вешалки, тележки | Мебель | `Метрическая система, мебель.rft` |
| Кубик: приборы, техника, оборудование, ёмкости | Специальное оборудование | `Метрическая система, специальное оборудование.rft` |
| Мойки, рукомойники | Сантехнические приборы | `Метрическая система, сантехнический прибор.rft` |
| Настенное (облучатели, диспенсеры, зеркала, сушилки, ТВ на стене) | категория по строкам выше | `Метрическая система, типовая модель на основе грани.rft` + `set_family_properties category` |

Проверка: `category` — категория из списка разрешённых. Соответствие строке таблицы — вручную.
