# Правила проекта «ПроПроект» — геометрия

Профиль `proproekt`, версия 0.2 (черновик: ждёт проверки человеком). Общие правила геометрии приходят из `global`: GEO-01 (без импорта и свободных форм) действует; GEO-02 и GEO-03 для LOD200 не обязательны — параметров размеров в семействах ПроПроекта нет.

| № | Правило | Проверка |
|---|---|---|
| PP-07 | LOD200: габарит и узнаваемый силуэт; скорость важнее детализации | Вручную, картинка проверки |
| PP-08 | Габариты — из колонки H (Ш×Г×В по спецификации), допуск 1 мм | `verify_families` (габарит по рёбрам) |
| PP-09 | Точка вставки: центр в плане, низ на уровне 0; на основе грани — центр по X, задняя грань на основе | Авто (`origin`, ось X) + `verify_families` |

### PP-07. LOD200

Семейство передаёт габарит и общий вид изделия: стол — столешница и опоры, шкаф — корпус, прибор — короб. Ручки, швы, крепёж, надписи не моделируются. Параметры на гранях (размеры с метками) не обязательны. Видимость форм по уровням детализации не настраивается.

Сделать:
- «кубик» — одно выдавливание по габариту; «цилиндр» — выдавливание круга Ø×H;
- «доработать» / «взять» — формы исходного семейства по эскизам из `family.json` (скрипт `build_families`):
  - тот же вид формы: выдавливание, вращение, сопряжение, сдвиг, сдвиг-сопряжение;
  - пустотные формы вырезают твёрдые через объединение геометрии (`CombineElements`);
  - вложенные семейства исходника переносятся их формами в основное семейство, в габарит своего экземпляра;
  - форму, которую Revit не принимает, упрощаем: сдвиг — брусья по сегментам пути с сечением профиля, остальное — короб по габариту формы. Каждое упрощение записывается в лог построения и в отчёт.

### PP-08. Габариты

Ш — вдоль X, Г — вдоль Y, В — вдоль Z; значения из колонки H таблицы (мм, как в спецификации). Цилиндр `Ø×H`: диаметр в плане, высота по Z. На основе грани (настенное): Ш — X, В — Y (вдоль стены), Г — Z (от стены).

Эскизы исходника масштабируются по осям; если длинная сторона исходника лежит поперёк ширины по спецификации, исходник сначала поворачивается на 90° в плане. После построения габарит измеряется по рёбрам и семейство пересобирается с поправкой (до трёх проходов) — допуск 1 мм.

Нет габаритов в спецификации — габарит исходного семейства или размер по аналогу; допущение записывается в задании, плане моделирования и отчёте (размеры в имя семейства не попадают).

Проверка: `verify_families` — габарит по рёбрам совпадает с заданием с точностью до 1 мм.

### PP-09. Точка вставки

- На уровне: начало координат — центр габарита в плане (X и Y), низ — на уровне 0. Так строятся кубики, цилиндры и перенос исходников на уровне. Настенные кубики тоже на уровне: высоту установки задают в проекте смещением.
- На основе грани (исходники Т39, Т7, сушилка для рук, рулонная штора): X — по центру ширины, задняя грань — на плоскости основы (Z = 0), положение по Y — как у исходника.

Проверка: `origin` по оси X (допуск 5 мм); Y и низ — `verify_families`.
