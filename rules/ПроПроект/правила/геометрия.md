# Правила проекта «ПроПроект» — геометрия

Профиль `proproekt`, версия 0.1 (черновик: ждёт проверки человеком). Общие правила геометрии приходят из `global`: GEO-01 (без импорта и свободных форм) действует; GEO-02 и GEO-03 для LOD200 не обязательны — параметров размеров в семействах ПроПроекта нет.

| № | Правило | Проверка |
|---|---|---|
| PP-07 | LOD200: габарит и узнаваемый силуэт; скорость важнее детализации | Вручную |
| PP-08 | Габариты — из колонки H (Ш×Г×В по спецификации) | Вручную, `get_family_geometry` |
| PP-09 | Точка вставки: центр в плане, низ на уровне 0; настенное — задняя грань на основе | Авто (`origin`, ось X) + вручную |

### PP-07. LOD200

Семейство передаёт габарит и общий вид изделия: стол — столешница и опоры, шкаф — корпус, прибор — короб. Ручки, швы, крепёж, надписи не моделируются. Параметры на гранях (размеры с метками) не обязательны: если быстрее без них — без них. Видимость форм по уровням детализации не настраивается.

Сделать:
- «кубик» — одно выдавливание (короб) или вращение/выдавливание круга (цилиндр) по габаритам;
- «доработать» / «взять» — формы исходного семейства по эскизам из `family.json`; эскизы масштабируются по осям так, чтобы общий габарит стал равен колонке H. Дуги при неравномерном масштабе строятся заново по трём точкам. Вложенные семейства исходника пересобираются отдельными семействами и вкладываются, либо их формы переносятся в основное семейство (LOD200 это позволяет).

### PP-08. Габариты

Ш — вдоль X, Г — вдоль Y, В — вдоль Z; значения из колонки H таблицы (в мм, как в спецификации). Для цилиндров `Ø×H`: диаметр в плане, высота по Z. Нет габаритов в спецификации — габарит исходного семейства (колонка D) или разумный размер по аналогу; допущение записать в колонку «Решение и комментарий».

Проверка: общий габарит по `get_family_geometry` совпадает с колонкой H с точностью до 1 мм (у «взять как есть» — с исходником).

### PP-09. Точка вставки

- Напольное: начало координат — центр габарита в плане (X и Y), низ — на уровне 0.
- Настенное (шаблон на основе грани): ось X — по центру ширины, задняя грань изделия — на плоскости основы, изделие выступает от неё.

Проверка: `origin` по оси X (допуск 5 мм); ось Y и низ — вручную по `get_family_geometry`.
