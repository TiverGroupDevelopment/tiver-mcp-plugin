# Правила проекта «ПроПроект» — источники и выдача

Профиль `proproekt`, версия 0.1 (черновик: ждёт проверки человеком). Объект — ЛДК ГБУЗ «МКНЦ им. А.С. Логинова ДЗМ», шифр 1747-Э/ПИР-2025, том ИОС6.ТХ1 «Медицинская технология». Семейства выдаются в Revit 2019.

| № | Правило | Проверка |
|---|---|---|
| PP-01 | Список работ — лист «Уникальные позиции» таблицы «Семейства» | Вручную |
| PP-02 | Геометрию берём по колонке «Решение»: кубик, доработать, взять | Вручную |
| PP-03 | Результат — `.rfa` Revit 2019 в `ПроПроект3/rvt/rfa` | Вручную |

### PP-01. Список работ — таблица «Семейства»

Таблица: [Семейства](https://docs.google.com/spreadsheets/d/1aMvrn6S3WLXfDEVAIENecSPkWMN92GhqtUdmtiv5Z3s/edit), лист «Уникальные позиции». Одна строка — одно семейство. Позиции не объединяем, даже если геометрия одинаковая (ламинарные боксы 4.34 и 4.39 — два семейства). Строки с одинаковым «Именем семейства» (дубли 4.38, 7.04 из-за пробелов в PDF) дают одно семейство.

Значения для семейства берутся из колонок: G — `ADSK_Наименование`, H — габариты для имени, I — `ADSK_Позиция`, J — `ADSK_Марка`, K — имя семейства. Колонки I–K — формулы, их не правят: правят G, H или исходные колонки A–C.

Мелкое оборудование, для которого семейства не делаются, уже отсеяно при заполнении таблицы: в ней остались только позиции, которые моделируем.

### PP-02. Источник геометрии — колонка «Решение»

| Решение (колонка F) | Откуда геометрия |
|---|---|
| «кубик» | Короб или цилиндр по габаритам из колонки H, строится скриптом в 2019 |
| «доработать: …» | Исходное семейство из колонки D: формы переносятся по эскизам из `family.json` и подгоняются под габариты из H |
| «взять как есть» | Исходное семейство из колонки D переносится без изменения размеров |
| «цилиндр: …» | Цилиндр Ø×H по габаритам из H |

Исходные семейства — в модели `ПроПроект3/rvt/proj/К01_ТХ_П_R24.rvt` (Revit 2024). Сохранить их в 2019 Revit не умеет, поэтому их данные сняты в Revit 2026 скриптом `collect_source_families` в `ПроПроект3/исходные семейства/<семейство>/` (`family.json`, `карточка.md`, `превью.png`). Свод — [projects/proproekt/исходные-семейства.md](../../../projects/proproekt/исходные-семейства.md).

Аналог из интернета брать можно, если он быстрее и есть в версии не новее 2019. Требования к параметрам и имени те же; импортированную геометрию (DWG, SAT) в семействе не оставлять (GEO-01).

### PP-03. Результат

- Файл: `ПроПроект3/rvt/rfa/<Имя семейства>.rfa`, сохранён в Revit 2019.
- Имя файла совпадает с именем семейства (колонка K).
- После сохранения — `check_family_rules profile: "proproekt"` и отметка в колонке «Статус» таблицы.
