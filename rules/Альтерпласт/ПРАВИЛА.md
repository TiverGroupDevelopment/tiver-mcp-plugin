# Правила моделирования семейств — проект «Альтерпласт»

Версия 1.1 · Nov 13, 2026 · Revit 2019 · профиль `alterplast` (`rules/Альтерпласт/profile.json`)

## Когда применять

Только для семейств проекта «Альтерпласт»: трубопроводная арматура и соединительные детали (краны, муфты, заглушки, отводы) по чертежам производителей. Профиль включается, когда пользователь явно называет проект или профиль. В других проектах эти правила не действуют.

Эталон — `Кран_шаровой_полный_проход_TEBO_ВН_ВН_бабочка.rfa`. Пример того, как делать не надо, — `Муфта_комбинированная_НР_под_ключ_PP_R.rfa`. Разбор обоих — в [РАЗБОР_ПРИМЕРОВ.md](РАЗБОР_ПРИМЕРОВ.md).

Как читать правила:

- **Авто** — правило проверяет `check_family_rules` с профилем `alterplast`. Статус: `fail` (нарушение), `warn` (проверить вручную) или `pass`.
- **Вручную** — правило проверяет человек или агент по чертежу и копии для инспекции.

### ALT-01. Таблица выбора вместо типоразмеров

Все типоразмеры (DN) живут в одной таблице выбора (CSV), а не в наборе типов семейства. Типов — один-два.

- **Ключ** — параметр экземпляра `DN1` (длина). Он же диаметр первого коннектора.
- **Размеры** — параметры экземпляра с формулой `size_lookup(LT, "<столбец>", <значение по умолчанию>, DN1)`.
- **Имя таблицы** — в текстовом параметре типа `LT`.
- **Тексты ADSK** — `ADSK_Наименование`, `ADSK_Код изделия`, `ADSK_Марка`, `ADSK_Масса`, `ADSK_Масса_Текст` тоже берутся из таблицы.
- **Нет строки в таблице** — `ADSK_Наименование` и `ADSK_Марка` показывают `Нет в каталоге` (значение по умолчанию `size_lookup`, без «!»): `size_lookup(LT, "ADSK_Марка", "Нет в каталоге", DN1, DN2)`.

Порядок:
1. CSV: первая строка — заголовки `DN1##length##millimeters,…`.
2. `manage_family_lookup_tables` action `import`.
3. Параметры — `add_family_parameters` (`isInstance: true`) и `set_family_parameter_formulas`.

CSV сохранять в ANSI (cp1251). Revit 2019 не читает UTF-8 с BOM (ошибка `InvalidHeaderSeparator`), а UTF-8 без BOM портит кириллицу в заголовках.

Ключей может быть несколько — первыми столбцами после имени строки, в том же порядке, что в `size_lookup`:
- `DN1` — всегда;
- `DN2` — у переходов и комбинированных муфт (диаметр второго коннектора; для резьбы — условный проход: 1/2" → 15, 3/4" → 20, 1" → 25…);
- `Исполнение` (целое) — когда у разных серий (C--TB, R-TB) одинаковые размеры, но разные артикулы.

Проверка: таблица есть, формул `size_lookup` больше нуля, типов не больше 2 (`lookupTable`); у `ADSK_Наименование` и `ADSK_Марка` значение по умолчанию `"Нет в каталоге"` (`lookupDefaults`).

### ALT-02. Материал через `ADSK_Материал`

Материал задаётся общим параметром типа `ADSK_Материал` (ФОП, тип «Материал»). Он связан:
- с параметром «Материал» каждой твёрдой формы — `associate_family_parameters`, `MATERIAL_ID_PARAM`;
- с `ADSK_Материал` вложенных семейств.

В самом семействе материал можно оставить пустым: его выбирают в проекте.

Проверка: параметр общий с GUID из ФОП, все твёрдые формы и вложенные семейства связаны с ним.

### ALT-03. Без лишней вложенности

Вложенные семейства — только там, где деталь действительно отдельная и повторяется (ручка-«бабочка» крана). Глубина — 1: во вложенном семействе нет своих вложенных. Экземпляров — не больше 3.

Всё, что можно сделать формой в основном семействе, делается формой.

Проверка: глубина не больше 1 (`fail`), экземпляров больше 3 — `warn`.

### ALT-04. У вложенных семейств нет галочки «Общий»

У вложенных семейств свойство «Общий» (`FAMILY_SHARED`) выключено: в проекте деталь считается одним изделием, а вложенное не всплывает отдельной строкой в спецификации.

Сделать: в документе вложенного семейства — `set_family_properties shared: false` до загрузки (`load_nested_family`).

Проверка: ни одно загруженное вложенное семейство не «Общее».

### ALT-05. Коннекторы связаны

Коннекторы проходной детали связаны попарно: поток и система трубы проходят через деталь. Один из коннекторов — главный.

Сделать: `setup_family_connectors` — два коннектора связываются автоматически, для тройника пары передаются в `link`.

Проверка: у каждого коннектора есть связанный.

### ALT-06. Ориентация: Y коннектора вверх, поток вдоль X

- Деталь лежит вдоль оси X: коннекторы смотрят в ±X, центр — в начале координат (см. ALT-14).
- Ось Y каждого коннектора направлена вверх (+Z семейства). Иначе при вставке в трубу деталь поворачивается вокруг оси, и ручка крана оказывается сбоку или снизу.
- «Всегда вертикально» — включено.

Сделать: `setup_family_connectors` (`orientUp` по умолчанию поворачивает коннектор вокруг своей оси).

Проверка: ось Y каждого коннектора совпадает с +Z.

### ALT-07. Классификация системы коннекторов — «Фитинг»

Классификация системы трубных коннекторов — `Fitting` («Соединительная деталь»): деталь берёт систему у трубы, а не задаёт свою.

Сделать: `create_family_connector systemType: "Fitting"` или `setup_family_connectors systemClassification: "Fitting"`.

Проверка: у всех трубных коннекторов `Fitting`.

### ALT-08. LOD 300

Модель передаёт форму и габариты изделия.

- **Моделировать:** корпус, присоединительные концы, шестигранники под ключ, ручку.
- **Не моделировать:** резьбу, надписи и гравировку (`create_family_model_text` для Альтерпласт не нужен), фаски меньше 1 мм, рёбра и мелкие элементы, которые не меняют габарит.

Видимость по уровням детализации — по умолчанию (все уровни).

Проверка: вручную, по копии для инспекции.

### ALT-09. Обработка ИД

Из исходных данных (чертёж, паспорт, каталог) берутся только **внешние габариты** и присоединительные размеры. Внутренние размеры нужны только для коннекторов: DN или условный проход задаёт их диаметр.

В таблицу выбора попадают только размеры, которые меняются с DN и влияют на внешнюю форму.

Проверка: вручную.

### ALT-10. По возможности единая геометрия

Корпус — одним телом там, где это возможно: тело вращения через `create_family_lathe_profile`, а не набор цилиндров. Отдельные формы — только для частей другой формы (шестигранник, ручка). Ориентир — не больше 6 форм на семейство.

Запрещены импортированная геометрия (DWG, SAT), свободные формы, DirectShape и текст модели.

Проверка: запрещённое — `fail`, форм больше 6 — `warn`.

### ALT-11. Геометрия на опорных плоскостях, параметры управляют плоскостями

Порядок построения:
1. Опорные плоскости — `create_family_reference_planes`.
2. Размеры между плоскостями с метками-параметрами — `create_family_dimensions label`.
3. Формы — их грани закрепляются на плоскостях (`align_family_elements`).

Параметр двигает плоскость, плоскость — геометрию.

Тело вращения вдоль X:
- станции по длине — плоскости с нормалью X, рисуются на виде «Спереди» (`view: "Спереди"`): торцы, уступы; размеры между ними с метками, общий размер и EQ относительно «По центру (Влево/Вправо)»;
- каждый диаметр — пара плоскостей `<D>_Верх` / `<D>_Низ`: размер с меткой `<D>` и EQ относительно «Опорная плоскость»;
- линии эскиза вращения закрепляются на этих плоскостях (как в эталонном кране). `align_family_elements` закрепляет только плоские грани, поэтому линии эскиза пока закрепляются кодом через `send_code_to_revit` (`NewAlignment` линии эскиза с плоскостью в виде «Спереди»). Это кандидат в отдельную команду.

Шестигранник — выдавливание на плоскости YZ: торцы закрепляются на станциях (`align_family_elements`), шесть сторон — на плоскостях `±S/2` с нормалями 90°, 30° и 150°. Все три размера несут метку «под ключ» `S`.

**Исключение:** шестигранники гаек и «под ключ». Размер «под ключ» допускается ставить на линии эскиза (метка на геометрии). Имя такого параметра содержит «Шестиуг…» или «под ключ».

Проверка: размеры с метками, которые ссылаются не на опорные плоскости и уровни (кроме исключения), дают `warn`.

### ALT-12. Инспекция: размеры в копии

**Временно не применяется (с 13.11.2026).** Копии `<имя>_инспекция.rfa` (`create_family_inspection_copy`) не делаются и в папку результатов не кладутся. Команда остаётся в плагине.

Готовое семейство по-прежнему не обмеряется размерами само. Проверка — по самому семейству: `test_family_flex` по всем строкам таблицы (размеры форм и положение коннекторов), `check_family_rules` и выгруженная таблица выбора (ALT-23) против ИД.

### ALT-13. Обязательные параметры

Общие параметры из ФОП профиля (`ФОП2019.txt`, ADSK 2019), добавлять командой `add_family_shared_parameters` с `sharedParameterFile`.

| Параметр | Тип | Группа | Как заполнять | Источник (ALT-22) |
|---|---|---|---|---|
| `ADSK_Единица измерения` | Текст | Данные | тип, формула `"шт."` | правило профиля |
| `ADSK_Завод-изготовитель` | Текст | Данные | тип, формула, например `"TEBO"` | бренд в наименовании перечня 1С и каталоге |
| `ADSK_Код изделия` | Текст | Данные | экземпляр, `size_lookup`, по умолчанию `""` | артикул из перечня 1С |
| `ADSK_Количество` | Число | Данные | тип, формула `1` | правило профиля |
| `ADSK_Марка` | Текст | Данные | экземпляр, `size_lookup`, по умолчанию `"Нет в каталоге"` | артикул из перечня 1С |
| `ADSK_Масса` | Число | Данные | экземпляр, `size_lookup` | масса из каталога, кг; в каталоге нет — 0 |
| `ADSK_Масса_Текст` | Текст | Данные | экземпляр, `size_lookup` | из каталога; нет — пусто |
| `ADSK_Наименование` | Текст | Данные | экземпляр, `size_lookup`, по умолчанию `"Нет в каталоге"` | наименование из перечня 1С |
| `ADSK_Обозначение` | Текст | Данные | экземпляр | заполняется в проекте |
| `ADSK_Позиция` | Текст | Данные | экземпляр | заполняется в проекте |
| `ADSK_Материал` | Материал | **Материалы и отделка** | тип, связан с формами (ALT-02) | выбирается в проекте |

Группы остальных параметров — как в эталоне: размеры и ключи `DN1`/`DN2` — «Размеры», `LT` — «Прочее». Группа задаётся при добавлении (`group` в `add_family_parameters` / `add_family_shared_parameters`): в API Revit 2019 группу существующего параметра изменить нельзя (в 2022+ — `update_family_parameters group`).

Проверка: все есть, общие, GUID совпадают с ФОП, `ADSK_Позиция` — экземпляр, `ADSK_Материал` — тип (`requiredParameters`); группы — `parameterGroups`.

### ALT-14. Семейство в центре пересечения опорных плоскостей

Центр габаритов детали совпадает с пересечением плоскостей «По центру (Влево/Вправо)», «По центру (Вперёд/Назад)» и «Опорная плоскость». Деталь строится симметрично относительно начала координат, в том числе по высоте.

Проверка: центр габаритов твёрдых форм в пределах 0.5 мм от начала координат по X, Y, Z.

### ALT-15. Опорные плоскости в пределах геометрии

Создаваемые опорные плоскости не длиннее геометрии **во всех видах**: ориентир — не больше трёх наибольших габаритов детали.

У плоскости две длины:
- `extent` — полудлина линии на виде, где плоскость рисуется;
- `depth` — полудлина в перпендикулярных видах (по умолчанию = `extent`). Без обрезки Revit тянет плоскость в перпендикулярных видах на 9 м (30 футов) — так «улетали» плоскости в первой версии муфт. `create_family_reference_planes` обрезает модельные границы плоскости во всех планах и фасадах.

Длина — по габаритам строк таблицы выбора (плоскости не растягиваются вместе с DN), но не больше 1,5 габарита строки по умолчанию. Например, для детали 50 мм `extent` 25–50.

Плоскости шаблона («По центру…», «Опорная плоскость») не трогаются.

Проверка: созданная плоскость хотя бы в одном виде длиннее 3× габарита — `fail`.

### ALT-16. Проход и внутреннюю геометрию не моделировать

Деталь моделируется сплошной по внешнему контуру. Проход, резьбу, внутренние полости, седло крана не строить. Важны внешние габариты и положение коннекторов (ALT-09).

`create_family_lathe_profile` — без `bore`.

### ALT-17. Нет размера — пропорционально чертежу

Если на чертеже нет нужного размера, его берут пропорционально изображению.

- Размер меняется с DN — заводится в таблицу выбора как доля известного размера (той же доли для всех DN).
- Размер постоянный — ставится числом.

Принятые допущения записываются в описание параметра (`update_family_parameters description`) и в отчёт. **Отдельных параметров под допущения (`Допущения_ИД` и т. п.) не заводить**: в семействе только ключи, размеры, `LT` и ADSK.

Проверка: `extraParameters` — запрещённые имена и текстовые параметры семейства, кроме `LT`.

### ALT-18. Категория и тип детали

| Деталь | Категория | Тип детали |
|---|---|---|
| Краны, клапаны (арматура) | «Арматура трубопроводов» (`OST_PipeAccessory`) | «Вставляется» (`BreaksInto`) |
| Муфты соединительные и разъёмные | «Соединительные детали трубопроводов» (`OST_PipeFitting`) | `Union` («Соединение») |
| Переходные и комбинированные муфты, штуцеры (разные DN на концах) | `OST_PipeFitting` | `Transition` |
| Заглушки, отводы, тройники | `OST_PipeFitting` | `Cap`, `Elbow`, `Tee`… |

Типа детали `Coupling` в Revit нет: обычная муфта — `Union`.

Шаблон — «Метрическая система, типовая модель». После него `set_family_properties category … partType …`: MEP-шаблонов в установке нет. Затем «Всегда вертикально» — да, «Общий» — нет.

### ALT-19. Коннектор раструба и внутренней резьбы — в глубине детали

Труба входит в муфту, а не упирается в её торец. Положение коннектора:

| Конец | Где коннектор | Откуда глубина |
|---|---|---|
| Раструб PP-R под сварку | на глубине раструба от торца | ИД (столбец глубины раструба); нет — пропорционально чертежу (ALT-17) |
| Внутренняя резьба (ВН, накидная гайка) | на длине свинчивания от торца | рабочая длина резьбы по ISO 7-1 (1/2" 13,2; 3/4" 14,5; 1" 16,8; 1¼"–1½" 19,1; 2" 23,4 мм), не больше 0,9 длины резьбовой части |
| Наружная резьба (НАР), хвостовик под сварку, буртик под гайку | на торце | — |
| Цанга PE-X | в глубине гайки цанги | пропорционально чертежу |

Глубина — параметр таблицы выбора: размер с меткой от торцевой плоскости до плоскости коннектора.

Как сделать в Revit 2019. API ставит коннектор только на грань формы, на опорную плоскость — нет. «Глубины вставки» у коннектора в 2019 тоже нет. Поэтому внутри корпуса строится невидимый стержень: выдавливание 3×3 мм, скрытое параметром формы «Видимый» = нет (выключить все уровни детализации сразу Revit не даёт: «Cannot make this element invisible in all levels of detail»). В проекте стержень не виден, коннекторы на его гранях работают. Его торцы закреплены на плоскостях коннекторов, коннекторы стоят на торцах стержня. Материал стержня тоже связан с `ADSK_Материал`.

Проверка: `connectorDepth` — коннектор вне габарита детали `fail`, все коннекторы на торцах `warn`, в деталях — глубина каждого. `test_family_flex` возвращает положение коннекторов по каждой строке таблицы.

### ALT-20. Имена размеров — как в ИД

- Ключи таблицы — всегда `DN1`, `DN2` (`Исполнение`) по ALT-01.
- Остальные размеры, которые есть в ИД, называются как в ИД: `L`, `L1`, `L2`, `H1`, `D`, `D1`, `D3`, `d`… Свои имена (`L_общ`, `S_гайка`) таким размерам не давать.
- Наружный Ø резьбы называется буквой резьбы из ИД (`G`, `D4`); значение — наружный Ø по ГОСТ 6357.
- Если обозначения на чертеже и в таблице расходятся (L и L1 перепутаны), имя и смысл берутся **по таблице**; расхождение — в описании параметра.
- Revit не различает регистр в именах параметров: `d` и `D` — один параметр. Если в ИД есть оба, у строчного добавляется описательный суффикс (`d_хвостовик` в 1.199), в описании — «ИД: d». Генератор проверяет такие совпадения.
- Размеры, которых в ИД нет (доли чертежа, ALT-17), называются описательно: `L_корпус`, `D_шейка`, `S_гайка`, `L_резьба`. В описании — доля и лист чертежа.

### ALT-21. Округление

- Значения из ИД — как в ИД (`52,85`, `69,84`).
- Вычисленные размеры (доли чертежа, `S = D·cos30°`, Ø резьбы по ГОСТ) — до 0,1 мм по правилам округления (0,25 → 0,3). Не `49,496`.

Генератор не пропускает вычисленный размер с двумя знаками. Проверка: `lookupDecimals` — в таблице выбора больше 2 знаков после запятой — `warn`.

### ALT-22. Источник каждого параметра ADSK

У каждого параметра ADSK есть источник: перечень 1С, каталог (ИД), правило профиля или «заполняется в проекте» (таблица в ALT-13). Значения без источника не придумывать: нет массы в каталоге — `0`, а не оценка.

### ALT-23. Таблицы выбора выгружаются в CSV пакетно

Таблицы выбора всех семейств папки результатов выгружаются одной командой:

```
export_family_lookup_tables folder: "<папка результатов>"
```

CSV пишутся в `<папка>/таблицы_выбора` в cp1251 (эту кодировку читает Revit 2019); резервные копии `*.0001.rfa` пропускаются. Это таблицы, которые реально лежат в семействах: по ним таблицы сверяются с ИД.

Собственная выгрузка Revit 2019 (`ExportSizeTable`) теряет кириллицу: «R-TB Муфта соединительная 20» → «R-TB », заголовок `L_общ` → `L_` без типа. Поэтому команда берёт из неё только число строк и типы столбцов, а имена столбцов и значения читает через API таблицы; числа пишутся без хвостовых нулей (`20`, `52.85`). Выгрузку сверять с CSV генератора: должна совпадать до ячейки.

## Порядок работы по профилю

1. `get_family_rules profile: "alterplast"` — прочитать правила, ФОП и обязательные параметры.
2. Разобрать ИД (ALT-09, ALT-17): таблица DN → внешние размеры, коннекторы, масса, тексты ADSK.
3. `new_family` (типовая модель) → `set_family_properties` категория и тип детали (ALT-18).
4. `add_family_shared_parameters` 11 параметров с группами (ALT-13) → параметры формы (`DN1`, размеры с именами из ИД — ALT-20, вычисленные до 0,1 мм — ALT-21, `LT`) → `manage_family_lookup_tables import` → формулы `size_lookup` с «Нет в каталоге» (ALT-01).
5. `create_family_reference_planes` с `extent` и `depth` (ALT-15), плоскости коннекторов на глубине (ALT-19) → `create_family_dimensions` с метками (ALT-11).
6. Геометрия: `create_family_lathe_profile` без прохода, `create_family_extrusion` для шестигранников (ALT-08, ALT-10, ALT-16) → `align_family_elements` на плоскости (ALT-11).
7. `associate_family_parameters` материал форм ← `ADSK_Материал` (ALT-02).
8. Стержень коннекторов на плоскостях коннекторов, скрыт параметром формы «Видимый» = нет (скрыть на всех уровнях детализации Revit не даёт) → `create_family_connector` на его торцах (ALT-19) → `setup_family_connectors systemClassification: "Fitting"` (ALT-05, ALT-06, ALT-07) → диаметры ← `DN1` / `DN2`.
9. Вложенные — только если нужно: `set_family_properties shared: false` во вложенном, затем `load_nested_family`, `place_family_instance` (ALT-03, ALT-04).
10. `test_family_flex` по всем DN из таблицы.
11. `check_family_rules profile: "alterplast"` → исправить `fail`, разобрать `warn`.
12. Описания параметров — источник каждого размера (ALT-17, ALT-20) → `save_family`.
13. `export_family_lookup_tables` по папке результатов (ALT-23) → сверить с ИД.
