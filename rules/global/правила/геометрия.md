# Общие правила — геометрия

Профиль `global`, версия 0.1 (черновик: ждёт проверки человеком). Действуют для любого семейства. Профиль проекта может ужесточить порог, сменить номер правила или отключить правило.

| № | Правило | Проверка |
|---|---|---|
| GEO-01 | Без импортированной и свободной геометрии | Авто (`singleGeometry`), `fail` |
| GEO-02 | Параметры управляют опорными плоскостями, а не геометрией | Авто (`labelsOnPlanes`), `warn` |
| GEO-03 | Опорные плоскости не длиннее геометрии во всех видах | Авто (`referencePlanes`), `warn` |

### GEO-01. Без импортированной и свободной геометрии

В семействе нет импортированной геометрии (DWG, SAT — `ImportInstance`), свободных форм (`FreeFormElement`) и `DirectShape`. Такая геометрия не управляется параметрами и утяжеляет проект.

Сделать: строить формами семейства — `create_family_extrusion`, `create_family_revolution`, `create_family_blend`, `create_family_sweep`, `create_family_swept_blend`.

Проверка: `singleGeometry` — запрещённый элемент даёт `fail`. Ориентир числа форм здесь не задан: его ставит проект (`maxForms`).

### GEO-02. Параметры управляют опорными плоскостями

Размер с меткой-параметром ставится между опорными плоскостями или уровнями, а грани форм закрепляются на плоскостях. Параметр двигает плоскость, плоскость — геометрию.

Сделать: `create_family_reference_planes` → `create_family_dimensions` с `label` → `align_family_elements` или `lock_family_sketch`.

Проверка: `labelsOnPlanes` — размер с меткой, который ссылается на геометрию, даёт `warn`. Исключения по именам параметров задаёт проект (`allowGeometryLabels`).

### GEO-03. Опорные плоскости не длиннее геометрии

Созданная опорная плоскость во всех видах не длиннее трёх наибольших габаритов детали. Без обрезки Revit тянет плоскость в перпендикулярных видах на 9 м.

Сделать: `create_family_reference_planes` с `extent` и `depth` по габаритам детали. Плоскости шаблона не трогаются.

Проверка: `referencePlanes` — плоскость длиннее 3× габарита хотя бы в одном виде даёт `warn`. Проект может поднять до `fail` (`severity`).
