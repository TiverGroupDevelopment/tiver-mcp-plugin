# Пакет ADSK — параметры

Профиль `adsk`, версия 0.1 (черновик: ждёт проверки человеком). Подключается профилем проекта: `"extends": ["global", "adsk"]`. Состав взят из профиля `alterplast` 1.1.

| № | Правило | Проверка |
|---|---|---|
| ADSK-01 | Обязательные общие параметры ADSK из ФОП проекта | Авто (`requiredParameters`) |

### ADSK-01. Обязательные параметры ADSK

В семействе есть общие параметры из ФОП проекта, GUID совпадают с ФОП.

| Параметр | Тип / экземпляр | Значение |
|---|---|---|
| `ADSK_Единица измерения` | — | постоянное: `"шт."` |
| `ADSK_Завод-изготовитель` | — | задаёт проект |
| `ADSK_Код изделия` | — | задаёт проект |
| `ADSK_Количество` | — | постоянное: `1` |
| `ADSK_Марка` | — | задаёт проект |
| `ADSK_Масса` | — | задаёт проект |
| `ADSK_Масса_Текст` | — | задаёт проект |
| `ADSK_Наименование` | — | задаёт проект |
| `ADSK_Обозначение` | — | заполняется в проекте Revit |
| `ADSK_Позиция` | экземпляр | заполняется в проекте Revit |
| `ADSK_Материал` | тип | см. ADSK-02 |

«—» значит, что пакет не требует типа или экземпляра: это решает проект.

Сделать: `add_family_shared_parameters` с `sharedParameterFile` из ответа `get_family_rules`.

Проверка: `requiredParameters` — параметр есть, он общий, GUID совпадает с ФОП; для `ADSK_Позиция` и `ADSK_Материал` проверяется тип или экземпляр. ФОП пакет не содержит: его задаёт профиль проекта (`sharedParameterFile`).

Проект может сменить номер правила, не повторяя список: `"requiredParameters": { "rule": "ALT-13" }`. Чтобы изменить состав, проект задаёт `parameters` целиком.
