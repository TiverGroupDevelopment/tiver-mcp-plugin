## Правила проекта в работе агента

Правила Альтерпласта применяются, когда проект назван в задаче: агент вызывает `get_family_rules profile: "alterplast"` (коллекторы — `"alterplast-multiport"`) и проверяет результат `check_family_rules` с тем же профилем. Без названного проекта действуют общие правила `global`. Все команды, включая свою команду проекта, доступны агенту всегда.
