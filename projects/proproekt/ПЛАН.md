# План: семейства ПроПроекта в Revit 2019

Составлен 2026-11-16. Правила — профиль [`proproekt`](../../rules/ПроПроект/profile.json), источник списка — таблица «Семейства», лист «Уникальные позиции» (161 строка, 159 семейств: две пары дублей 4.38 и 7.04).

## Объём

| Решение в таблице | Позиций | Как делаем |
|---|---|---|
| кубик | 65 | короб по габаритам, скрипт `build_lod200` |
| цилиндр | 3 (5.08, 5.09, газификатор) | цилиндр Ø×H, тот же скрипт |
| доработать | 82 + 1 «взять за основу» | перенос исходного семейства по эскизам с подгонкой габарита, скрипт `rebuild_from_source` |
| взять как есть | 11 | перенос исходного семейства без изменения размеров, тот же скрипт |

Исходных семейств — 51 (снято 2026-11-16, [свод](исходные-семейства.md)): импорта и свободных форм нет ни в одном, сложность переноса — 22 простых, 19 средних, 10 сложных. `ADSK_Устройство условное цилиндр` не снято и не нужно: цилиндры строятся заново.

## Этап 0. Подготовка (до работы в 2019)

1. Собрать и установить плагин для 2019: `dotnet build tiver-mcp-plugin.sln -c "Release R19"`, `.\scripts\install-local.ps1 -Year 2019 -AutoStart on` (Revit 2019 закрыт). Убрать дублирующий манифест `revit-mcp.addin` в `Addins\2019`, как сделано для 2026.
2. Подключить агенту MCP-сервер `revit-local` (сессия Claude Code в корне репозитория) или вызывать команды плагина напрямую по порту.
3. В таблицу добавить колонки «Статус» и «Файл .rfa».

## Этап 1. Скрипты проекта (`projects/proproekt/scripts/`)

| Скрипт | Где запускается | Что делает |
|---|---|---|
| `collect_source_families` | Revit 2026, проект R24 | готов: снимает `family.json` по семействам |
| `build_lod200` | Revit 2019 | новое семейство по шаблону категории; короб или цилиндр по габаритам; три параметра ADSK; сохранение `<Имя семейства>.rfa` |
| `rebuild_from_source` | Revit 2019 | новое семейство; формы из `family.json` (выдавливание, сопряжение, вращение, сдвиг, сдвиг-сопряжение) по эскизам, масштаб под габарит из таблицы; вложенные — переносом их форм; три параметра ADSK; сохранение |

Скрипт, который отработал на пилоте и нужен на десятках семейств, становится командой набора «ПроПроект» (`"sets": ["ПроПроект"]`, `status: experimental`). Кандидаты: `export_family_recipe` (Revit 2025+) и `build_family_from_recipe` (Revit 2019); после проверки на втором проекте — в Global ([PROMOTION.md](../../PROMOTION.md)).

## Этап 2. Пилот (5 семейств, показать до массовой работы)

| Позиция | Решение | Исходник | Что проверяем |
|---|---|---|---|
| 3.01 Стол медицинский | доработать | М28, 3 выдавливания | подгонка габарита 600×900 → 1200×600×750 |
| 3.13 Тумба подкатная | доработать | О79, выдавливание и 3 сдвига | перенос сдвигов |
| 1.24 Кресло офисное | взять как есть | М42, 16 форм | сложный перенос без масштаба |
| 4.37 CO2-инкубатор | кубик | — | короб, категория, параметры |
| 5.08 Криохранилище | цилиндр | — | цилиндр |

По каждому: `check_family_rules profile: "proproekt"`, `get_family_geometry` (габарит), `capture_family_view` (картинка), загрузка в пустой проект 2019. Итоги пилота — правки правил и скриптов, затем согласование с вами.

## Этап 3. Массовая работа

1. Кубики и цилиндры (68): одним прогоном скрипта по строкам таблицы.
2. Перенос по группам исходных семейств, от простых к сложным: столы М28/М1/О24 (лабораторные и офисные столы), шкафы М36/О16/М12.2/М70/М38/М39, тумбы О79/О17, аксессуары И*, техника Т*, затем стулья и кресла, ВК-2 (5 вложенных), АРМ, сушка для рук.
3. АРМ 7.03, 7.06, 7.12 — одно семейство-образец и копии с другими параметрами (PP-06).
4. После каждой группы — проверка правилами и отметка «Статус» в таблице.

## Этап 4. Выдача

- `.rfa` Revit 2019 в `ПроПроект3/rvt/rfa`, имя файла = имя семейства.
- Превью PNG по готовым семействам, ссылка на файл в таблице.
- Сводная проверка `check_family_rules` по всей папке.

## Риски

- **Неравномерный масштаб дуг.** Скругления и круглые ножки при подгонке габарита искажаются; для LOD200 допустимо, дуги строятся по трём точкам.
- **Сдвиги по 3D-пути** (Т6 телевизор, сушка для рук) переносятся сложнее; при неудаче — упрощение до выдавливаний.
- **Сторонние надстройки.** В Revit 2026 обновлятор ClaudeRevit ломает часть операций; в Revit 2019 перед массовой работой проверить надстройки.
