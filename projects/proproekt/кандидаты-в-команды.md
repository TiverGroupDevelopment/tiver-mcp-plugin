# Кандидаты в команды (ПроПроект)

Что при моделировании семейств ПроПроекта пришлось делать через `send_code_to_revit` — готовых команд не хватило. Код лежит в [scripts/](scripts/) и проверен на 159 семействах в Revit 2019 (сбор — в Revit 2026). Порядок — по пользе.

| № | Будущая команда | Скрипт сейчас | Что делает | Почему нет готовой команды | Набор |
|---|---|---|---|---|---|
| 1 | `export_family_recipe` | [collect_source_families](scripts/collect_source_families.cs) | Снимок семейства проекта в JSON: категория, размещение, параметры с формулами и значениями по типоразмерам, формы с эскизами (кривые в мм), опорные плоскости, размеры с метками, вложенные семейства с трансформами, копия `.rfa` | `get_family_geometry` отдаёт грани и габариты, но не эскизы форм в виде, пригодном для пересборки; пакетного обхода семейств проекта нет | Global |
| 2 | `build_family_from_recipe` | [build_families](scripts/build_families.cs) | Новое семейство по снимку: те же виды форм по эскизам, аффинное преобразование (поворот 90°, масштаб по осям, центр), вложенные — их формами в габарит экземпляра, пустотные — вырезание, упрощения LOD200, подгонка габарита в несколько проходов | Это «понижение версии» семейства: Revit не сохраняет в старую версию. Отдельные `create_family_*` не умеют массово и не знают про снимок | Global после проверки на втором проекте |
| 3 | `create_box_family` (или параметр `shape` у `new_family`) | `build_families`, `kind: box/cylinder` | Семейство-кубик или цилиндр по габариту: шаблон, категория, одно выдавливание, общие параметры с значениями, типоразмер с именем, сохранение | Сейчас это 5–6 вызовов команд на одно семейство; для 67 кубиков нужен один пакетный вызов | ПроПроект → Global |
| 4 | `verify_families` | [verify_families](scripts/verify_families.cs) | Пакетная проверка готовых `.rfa`: версия файла, имя, категория, общие параметры (GUID из ФОП, тип/экземпляр, значения), типоразмеры, точный габарит по рёбрам, точка вставки, импорт; выгрузка сетки треугольников | `check_family_rules` проверяет правила, но не сверяет значения параметров и габарит с внешним заданием и работает по одному файлу | ПроПроект |
| 5 | `export_family_mesh` | `verify_families` (сетки) + [tools/render_proof.py](tools/render_proof.py) | Треугольники геометрии семейства для картинок вне Revit | В Revit 2019 `Document.ExportImage` у фонового документа открывает его в окне, после чего документ нельзя закрыть из API (см. ниже). `capture_family_view` в 2019 стоит перепроверить | Global |
| 6 | `close_documents` | разовый `send_code` | Закрыть все документы, кроме активного, без сохранения | После сбоя остаются открытые документы; закрыть их нечем | Global |

## Что выяснилось про Revit API (пригодится командам)

- **Профиль сдвига** (`NewSweep`, `NewSweptBlend` с `NewCurveLoopsProfile`) задаётся в локальных осях: начало — точка пути, X = N×T, Y = N (N — нормаль плоскости пути, T — касательная). Профиль в координатах модели Revit отвергает («One of the conditions for the inputs was not satisfied»). Проверено опытом в Revit 2019.
- **`ProfilePlaneLocation`** в 2019: `Start`, `MidPoint`, `End` (не `Middle`).
- **Точки эскиза** должны лежать на плоскости точно: координаты, округлённые до 0,01 мм, на наклонных плоскостях дают отказ. Перед созданием проецировать на плоскость.
- **`NewExtrusion`** строит на положительную длину; начало больше конца (6,35 → −6,35) задаётся после создания через `StartOffset`/`EndOffset`.
- **Пустотные формы** в семействе режут твёрдые только через `Document.CombineElements` (`SolidSolidCutUtils` для форм возвращает «нельзя»). После объединения геометрия принадлежит `GeomCombination`, форма свою геометрию не отдаёт — замеры должны учитывать объединения.
- **`Solid.GetBoundingBox`** для дуг даёт неточную оболочку (до 4 мм); точный габарит — по разбивке рёбер.
- **Семейства на основе грани** содержат плиту-основу шаблона 2438,4×2438,4×304,8 мм — исключать из габарита.
- **`send_code_to_revit`** ждёт ответа 60 с, потом отвечает таймаутом, но код в Revit выполняется дальше. Длинные пакеты — с логом в файл.
- **Сторонние надстройки:** в Revit 2026 обновлятор ClaudeRevit откатывает операции с семейством `ADSK_Устройство условное цилиндр`.
