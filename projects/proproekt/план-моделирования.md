# План моделирования семейств ПроПроекта (Revit 2019)

Сгенерирован из `jobs.json` скриптом [tools/make_plan.py](tools/make_plan.py) по таблице «Семейства» (лист «Уникальные позиции») и снимкам исходных семейств. Правила — профиль [`proproekt`](../../rules/ПроПроект/profile.json).

## Исходные данные

- Спецификация ИОС6.ТХ1, листы 34–113: 668 позиций в 73 разделах (72 помещения и «Улица»), 161 уникальная строка таблицы.
- Семейств к моделированию: 159. Строки-дубли с одинаковым именем (4.38, 7.04 — разные пробелы в PDF) дают одно семейство.
- Исходные семейства — 51 из модели `К01_ТХ_П_R24.rvt` (снимок в `ПроПроект3/исходные семейства`).

## Способ построения

| Способ | Семейств | Как |
|---|---|---|
| кубик | 64 | одно выдавливание по габариту Ш×Г×В, центр в плане, низ на 0 |
| цилиндр | 3 | выдавливание круга Ø×H |
| перенос исходника | 92 | формы исходного семейства по эскизам с подгонкой под габарит; вложенные семейства — их формами |

Перенос исходника:
- Преобразование: при необходимости поворот на 90° в плане (длинная сторона — вдоль ширины), масштаб по осям под Ш×Г×В, центр в плане — в начало координат, низ — на уровень 0.
- Формы: выдавливание, вращение, сопряжение, сдвиг, сдвиг-сопряжение — тем же видом формы. Пустотные формы вырезают твёрдые (объединение геометрии).
- Упрощения LOD200, если Revit не принимает форму: сдвиг — брусья по сегментам пути с сечением профиля; иначе — короб по габариту формы.
- Подгонка габарита: построить → измерить по рёбрам → пересобрать с поправкой (до 3 проходов, лучший). Допуск — 1 мм.

## Порядок работ

1. Задания: `tools/make_jobs.py` по выгрузке листа «Уникальные позиции» и снимкам исходников.
2. Построение: скрипт `scripts/build_families` в Revit 2019 партиями по 8 (лог `моделирование/build-log.jsonl`).
3. Проверка: `scripts/verify_families` (версия, имя, категория, параметры и GUID, типоразмер, габарит, точка вставки, импорт) и `tools/check_rules.mjs` (команда плагина `check_family_rules` с проверками профиля `proproekt`).
4. Картинки: `tools/render_proof.py` — изометрия и три проекции с габаритами.
5. Отчёт: `tools/make_report.py`.
